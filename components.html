        Liquid glass

        DOM port of the liquid-glass-js API — new Container({ type, borderRadius, tintOpacity }), new Button({ text, size, type, warp, onClick }), container.addChild(). Chromium gets real edge refraction through an SVG displacement map; other browsers get frosted blur + rim light. Everything below is built with the JS API.

        WebGL islands

        Lazy-loaded React islands — downloaded only when scrolled into view, with a static fallback when WebGL is unavailable.
